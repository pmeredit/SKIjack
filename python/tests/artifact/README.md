# Reference artifact (vendored copy)

These four scripts are the oracle the test suite checks the compiler
against: the hand-built self-interpreter and its scry harnesses from the
paper's artifact repository,
<https://github.com/sigilante/artifact-metacircular-ski>, copied verbatim
from commit `486fd8c21cbaa983025a499c9c8c3789d8523095` (2026-09-20). MIT,
same author; the LICENSE alongside is that repository's.

Do not edit them here. To refresh, copy the files from a checkout of that
repository and update the commit above. To test against a live checkout
instead, set `SKIJACK_ARTIFACT_DIR` to it.
